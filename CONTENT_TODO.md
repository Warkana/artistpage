# Що потрібно від Юлії перед запуском

Сайт зібраний і працює на плейсхолдер-контенті. Нижче — усе, що потрібно
замінити на реальні дані (відповідає розділу 08 ТЗ).

## 1. Роботи — `src/data/works.ts`

Для кожної з 10 робіт (`work-01` … `work-10`):

- [ ] Назва (UA + EN)
- [ ] Рік
- [ ] Розмір
- [ ] Техніка/матеріали (зараз усюди стоїть плейсхолдер "Акварель, папір" — перевірити)
- [ ] Серія/тема (наприклад "Портрети", "Вода") — після заповнення в галереї
      автоматично з'явиться фільтр за серіями
- [ ] Статус: `available` / `sold` / `on-request`
- [ ] Короткий опис роботи (UA + EN), необов'язково

Також варто додати кілька фото на роботу (деталі, процес) — компонент
`ArtworkGallery` вже підтримує масив зображень, зараз використовується по 1.

## 2. Контакти — `src/data/contacts.ts`

- [ ] Email
- [ ] Instagram (посилання + @handle)
- [ ] Telegram (посилання + @handle)
- [ ] WhatsApp (номер у міжнародному форматі)
- [ ] Viber (номер)

## 3. Тексти — `src/i18n/index.ts`

- [ ] `about.bio` — реальна біографія (UA + EN)
- [ ] `about.statement` — мистецька заява (UA + EN)

## 4. Фото художниці

- [ ] Портретне фото для сторінки "Про мене" (зараз — заглушка з підписом)
      → `src/views/AboutView.astro`

## 5. Технічне перед запуском

- [ ] Web3Forms access key у `src/views/ContactView.astro`
      (безкоштовно на web3forms.com, без бекенду)
- [ ] Реальний домен у `astro.config.mjs` (`SITE_URL`) — впливає на
      sitemap.xml і Open Graph URL
- [ ] GA4 / Meta Pixel ID у `src/layouts/BaseLayout.astro` (зараз
      закоментовано навмисно — не вмикати без реальних ID)
- [ ] Фавікон/лого — зараз стоїть дефолтний Astro-фавікон у `public/`
